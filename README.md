
# Java Socket Chat Application

## Project Overview
A real-time chat application using Java Socket Programming.

## Features
- Client-server communication
- Multithreading for client connections
- Real-time message exchange
- Console-based client and server

## Technologies
- Java
- Socket Programming
- Multithreading
- GitHub Actions for CI

## Project Files
- Server.java
- Client.java

## How It Works
The server listens on port 5000 and accepts client connections.
The client connects to the server and sends messages.
The server responds to messages received from the client.
